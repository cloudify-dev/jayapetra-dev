# Admin CMS Yakapetra

React + TypeScript + Vite + Tailwind + Zustand + Axios

## Setup

1. **Pastikan backend sudah jalan** (lihat `backend/README.md`)

2. **Install & jalankan**
   ```bash
   cd admin && npm install
   npm run dev
   ```

3. Buka http://localhost:5174

4. Login dengan akun admin (dari `npm run db:seed` di backend)
